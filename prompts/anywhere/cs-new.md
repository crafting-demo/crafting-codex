description: New thread in the Crafting Sandbox workspace, which lands in a fresh sandbox
---

Create a new thread in the **Crafting Sandbox** workspace, on the
**codex-cloud** connection.

Use your new-chat tool and do it now. This command is the go-ahead: do not ask
first, and do not tell the user to press the button themselves.

The workspace and the connection are the point. A thread created anywhere else
runs locally and gets no sandbox. If that workspace does not exist, say so
rather than falling back to a local thread.

Then say one sentence: the chat is ready, and their first message in it lands
in a fresh sandbox. The router claims the sandbox on that first message, so do
not call it ready before then.

Never run `cs sb create` for this. A new Crafting sandbox means a new thread in
that workspace, full stop.
